# ADR-0001：飞书完成状态受控双向同步

## 状态

已接受，2026-08-31。

## 背景

用户要求在 FeedNote、FeedNote 计划表和对应飞书待办之间双向同步任务完成状态。本地桌面应用没有稳定公网回调地址，不能可靠接收飞书 Webhook。

## 决策

- 应用运行时每 30 秒轮询一次已启用的飞书计划表和已映射飞书任务；“立即同步”执行同一流程。
- 每轮先拉取远端完成状态，再推送本地待同步变化。
- 飞书计划表只读取“本地计划ID”和“状态”两列；飞书任务只读取已保存 GUID 对应任务的完成状态。
- 远端只能把已有计划切换为完成或重新打开。不得新建、删除计划，不得改写标题、正文、时间、链接、注意事项和来源。
- 本地存在尚未上传的变化时，本地优先；远端回读通过 `updated_at` 条件更新，防止读取期间的本地操作被覆盖。
- 飞书计划表与飞书任务状态冲突时，计划表在当前轮先处理；得到的新本地版本随后覆盖任务旧状态。
- 每次接受远端状态都写入审计日志，并触发本地 `plans-changed` 事件。

## 不包含

- 投递记录表反向生成计划；
- 从飞书新增计划、删除计划或同步内容字段；
- 公网 Webhook 服务、离线后台服务和应用关闭时同步；
- 多设备数据库同步、协作编辑或冲突合并。
